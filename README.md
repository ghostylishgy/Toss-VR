# Toss VR

A spatial coin-toss interaction experiment for **Meta VR Glasses**.

> **Project principle:** Don't build a coin-toss app that happens to run in glasses. Make it feel like the real world suddenly contains one digital coin.

## Competition build rule

**One coin, polished to the limit.**

The competition build prioritizes:

1. Grab / pinch
2. Toss
3. Physical flight and rotation
4. Catch or graceful recovery
5. Heads / tails result
6. Minimal decision mode

No dashboard, no virtual room, no feature sprawl.
